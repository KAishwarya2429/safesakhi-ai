Requirements Document

1. Application Overview
   Application Name: SafeSakhi AI

Description: An autonomous multi-agent women's safety command center web application that provides real-time journey protection, risk intelligence, and emergency response coordination through five specialized AI agents.

2. Users and Usage Scenarios
   Target Users: Women who need safety monitoring during travel or daily commutes

Core Usage Scenarios:

Starting a journey and receiving continuous safety monitoring
Receiving automated safety check-ins during travel
Getting emergency assistance when failing to respond to check-ins
Viewing real-time risk assessments for locations and routes
Managing trusted contacts for emergency notifications 3. Page Structure and Functionality

4.1 Journey Protection Mode
Mission Creation:

When user starts journey protection, system generates unique mission ID
Mission records destination, travel mode, expected duration, start time
All five agents activate upon mission creation
Automated Check-in Process:

System sends check-in prompt at configured intervals
User has 2-minute grace period to respond
Check-in response records timestamp and user status
Escalation Protocol:

Tier 1: If user fails to respond within 2 minutes, system sends push notification reminder
Tier 2: If no response after Tier 1, Trusted Contact Agent sends automated notifications to all trusted contacts
Tier 3: If no response after Tier 2, Emergency Coordinator Agent triggers full emergency protocol including location sharing and evidence collection
4.2 Risk Intelligence
Risk Score Calculation:

Risk Intelligence Agent analyzes location risk scores (0-100 scale)
Factors include: time-of-day patterns, historical incident data, weather conditions
Risk score updates in real-time during journey
Color coding: 0-33 (green/safe), 34-66 (yellow/moderate), 67-100 (red/high risk)
4.3 Route Monitoring
Route Guardian Agent Functions:

Monitors journey progress against expected route
Detects deviations from planned route
Calculates safe route alternatives when deviation detected
Alerts user of safer route options
4.4 Emergency Response
SOS Activation:

User taps SOS button to instantly activate emergency protocol
Emergency Coordinator Agent orchestrates all agents
Evidence Agent captures timestamped location, route history
Trusted Contact Agent notifies all trusted contacts
System generates incident report
Agent Coordination:

Emergency Coordinator Agent receives alerts from other agents
Coordinates response actions across all agents
Manages communication flow between agents
Escalates to simulated authority contact when necessary
4.5 Evidence Collection
Evidence Agent Functions:

Captures timestamped location logs throughout journey
Records audio/video evidence triggers during emergency
Stores incident reports with all collected evidence
Maintains evidence chain for incident history
4.6 Demo Mode
Demo Flow Execution:

Demo mode allows access without login
Simulates complete journey protection scenario
Demonstrates missed check-in and autonomous escalation
Shows all agent activities and emergency response coordination
Duration: 3 minutes 5. Exception and Boundary Cases
Scenario Handling
User loses internet connection during journey System stores last known location, resumes monitoring when connection restored
User ends journey early User manually ends mission, system records actual end time and route
No trusted contacts configured System prompts user to add trusted contacts before starting journey
Invalid destination input System displays error message, requests valid destination
User responds to check-in after grace period System records late response, continues monitoring without escalation
Multiple active missions System allows only one active mission at a time, prompts to end current mission before starting new one
Demo mode limitations Demo mode displays simulated data, does not store real user information 6. Acceptance Criteria
User registers account with email and password, successfully logs in to Dashboard
User starts Journey Protection Mode by entering destination and travel mode, system creates mission with unique ID
System sends automated check-in prompt at configured interval, user responds successfully
User simulates missed check-in, system autonomously escalates through Tier 1, Tier 2, and Tier 3 protocols
User views Agent Hub showing all five agents active with real-time status and message flow
User taps SOS button, Emergency Coordinator Agent activates full emergency response and Evidence Agent captures incident data
User views Incident History showing generated incident report with timestamped evidence
User ends journey, system records mission completion and returns to Dashboard 7. Out of Scope for Current Release
